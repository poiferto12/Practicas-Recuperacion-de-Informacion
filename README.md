# Sistema de Recuperación de Información sobre CORD-19

Proyecto académico desarrollado en Java para indexar, buscar y evaluar documentos científicos de la colección CORD-19 mediante Apache Lucene.

El objetivo del proyecto es aplicar los principales conceptos de recuperación de información: creación de índices, procesamiento de consultas, análisis de términos y evaluación de sistemas de búsqueda.

## Funcionalidades

* Lectura y procesamiento de documentos científicos.
* Indexación de campos mediante Apache Lucene.
* Indexación concurrente utilizando varios hilos.
* Ejecución de consultas sobre uno o varios campos.
* Obtención de estadísticas de términos.
* Cálculo y análisis de TF, IDF y TF-IDF.
* Comparación de diferentes configuraciones de búsqueda.
* Evaluación de resultados mediante métricas de recuperación de información.
* Procesamiento de archivos CSV, JSON y XML.

## Conjunto de datos

El proyecto utiliza la colección CORD-19, un conjunto de documentos científicos relacionados con el COVID-19.

Los archivos completos de la colección no se incluyen en el repositorio debido a su tamaño. Para ejecutar determinadas prácticas es necesario descargar o proporcionar los datos por separado.
